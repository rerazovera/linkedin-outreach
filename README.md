# LinkedIn Outreach + Brevo 24h

**Despliegue Dokploy:** lea `DOKPLOY_INSTALACION_LIMPIA.md`.

Aplicación React + Node.js + MariaDB. Mensajes de LinkedIn preparados para envío manual; emails individuales mediante Brevo y cola persistente hasta 24 horas.

Acceso inicial: `admin`, contraseña en `.env` (ADMIN_PASSWORD).

La aplicación no envía mensajes privados automáticamente por LinkedIn.
